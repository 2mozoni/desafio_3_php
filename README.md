🔐 Desafio 3: Sistema de Autenticação e Perfil em PHP

Este projeto é um desafio prático focado no desenvolvimento de um sistema de login funcional utilizando PHP e Sessões para controle de acesso, com suporte a persistência de dados em banco de dados e personalização de interface.

🚀 Funcionalidades

🔑 Login de Usuário: Autenticação de credenciais comparando os dados informados com os registrados no banco de dados.

🛡️ Controle de Acesso por Sessão: Proteção de páginas restritas através das sessões nativas do PHP (session_start()).

👤 Página de Perfil Protegida: Acesso exclusivo para usuários devidamente autenticados no sistema.

🎨 Personalização de Tema: Opção para alterar e salvar a cor de fundo da página de perfil do usuário.

🚪 Logout Seguro: Destruição completa da sessão do usuário (session_destroy()) com redirecionamento para a tela de login.

🛠️ Tecnologias Utilizadas

Linguagem: PHP 8.x

Banco de Dados: MySQL / MariaDB (via PDO ou MySQLi)

Front-end: HTML5
